# Millie 2.91

**Browse for Me.** Type a question in the command bar and press **Tab**. Millie opens a full-window "Browsing for you…" screen while it searches the web and reads the top results, then settles into a chat-style page: a cited answer, the sources it read, and an **Ask a follow-up…** box to keep going. Works with Local Codex or your own Claude / GPT / Gemini key.

Your question goes to DuckDuckGo and page excerpts go to your chosen AI provider only when you press Tab. The page is served from a local, loopback-only server with a per-conversation secret.

**Fix:** opening the command bar could freeze the app (spinning beachball) when the audio input system was slow to respond. The microphone is now only touched when you actually use dictation.
